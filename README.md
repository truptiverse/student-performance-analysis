# 📊 Student Performance Analysis

A beginner-friendly data analytics project exploring student performance using Python, Pandas, SQL, PostgreSQL, and data visualization.

## 🎯 Objective

The goal of this project is to analyze student performance and understand how factors such as study hours and attendance relate to academic scores.

## 🛠️ Tools & Technologies

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 🧮 SQL
- 🐘 PostgreSQL
- 💻 Git & GitHub
